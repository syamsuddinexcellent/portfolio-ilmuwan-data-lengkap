2. Kamus data dan frekuensi pembaruan¶

Frekuensi pembaruan diamati langsung dari data: berapa kali nilai berubah per tahun, dan pada tanggal berapa perubahan terjadi.

In [3]:
meta = {
    'OIL': ('Harga minyak mentah', 'USD/barel'),
    'GOLD': ('Harga emas', 'USD/troy ounce'),
    'USDIDR': ('Kurs dolar AS terhadap rupiah', 'IDR per USD'),
    'SP500': ('Indeks saham S&P 500 (AS)', 'poin indeks'),
    'IHSG': ('Indeks Harga Saham Gabungan (BEI)', 'poin indeks'),
    'VIX': ('Indeks volatilitas tersirat pasar opsi AS', 'poin'),
    'CPI': ('Inflasi Indonesia (nilai konsisten dengan inflasi rata-rata tahunan)', '% per tahun'),
    'BI_rate': ('Suku bunga acuan Bank Indonesia', '% per tahun'),
    'US_rate': ('Suku bunga kebijakan AS (Fed funds)', '% per tahun'),
}
years = (df.Date.max() - df.Date.min()).days / 365.25
first_day = list(df.groupby(df.Date.dt.to_period('M')).Date.min())   # hari kerja pertama tiap bulan
rows = []
for c in VARS:
    s = df[['Date', c]].dropna()
    changed = s[c].ne(s[c].shift())
    changed.iloc[0] = False
    cp = s.loc[changed, 'Date']
    on_first = cp.isin(first_day)
    per_year = len(cp) / years
    if per_year > 100:
        cat, freq = 'Harian', 'Harian'
    elif on_first.all() and cp.dt.month.eq(1).all():
        cat, freq = 'Tahunan', 'Tahunan (hari kerja pertama Januari)'
    elif on_first.all():
        cat, freq = 'Bulanan', 'Bulanan (hari kerja pertama tiap bulan)'
    elif on_first[cp < cp[~on_first].min()].all():
        cat, freq = 'Campuran', f'Awal bulan s.d. {cp[~on_first].min():%b %Y}, lalu tanggal keputusan'
    else:
        cat, freq = 'Tidak beraturan', 'Tidak beraturan'
    rows.append({'Variabel': c, 'Deskripsi': meta[c][0], 'Satuan': meta[c][1], 'Tipe': str(df[c].dtype),
                 'Nilai unik': s[c].nunique(), 'Perubahan/tahun': round(per_year, 1),
                 'Kategori': cat, 'Frekuensi teramati': freq})
dictionary = pd.DataFrame(rows)
display(dictionary)
dictionary.to_csv(REP / 'raw_data_dictionary.csv', index=False)

Temuan: variabel pasar (OIL, GOLD, USDIDR, SP500, IHSG, VIX) bersifat harian. US_rate selalu berubah pada hari kerja pertama tiap bulan, CPI hanya pada hari kerja pertama Januari, sedangkan BI_rate memiliki dua rezim: berubah di awal bulan hingga awal 2016, lalu mengikuti tanggal pengumuman kebijakan. Pola ini penting karena nilai bulanan/tahunan yang "ditempel" sejak awal periode belum tentu sudah diketahui pada tanggal tersebut — indikasi look-ahead bias yang divalidasi pada Unit 4.

5. Distribusi return harian IHSG¶

Return dihitung hanya pada hari ketika IHSG benar-benar berubah (hari libur BEI, yang nilainya disalin, dikeluarkan sementara — penanganan formal ada di Unit 6).

from scipy import stats

ihsg = df[['Date', 'IHSG']].dropna()
ihsg = ihsg[ihsg.IHSG.diff().ne(0)].copy()
ihsg['ret'] = ihsg.IHSG.pct_change() * 100
r = ihsg['ret'].dropna()
share_3sd = (r.sub(r.mean()).abs() > 3 * r.std()).mean() * 100
normal_3sd = 2 * stats.norm.sf(3) * 100

print(f'Jumlah hari bursa BEI : {len(ihsg):,}')
print(f'Rata-rata return      : {r.mean():.3f}% per hari | simpangan baku: {r.std():.3f}%')

6. Hubungan antarvariabel (periode eksplorasi 2010–2022)¶

Korelasi pada level harga menyesatkan karena semua deret memiliki tren (korelasi semu). Karena itu hubungan diukur pada return harian, dengan korelasi Spearman yang tahan terhadap pencilan (data mentah masih berisi kutipan janggal).

In [7]:
eda = df[(df.Date <= EDA_END)].dropna(subset=['IHSG']).copy()
eda = eda[eda.IHSG.diff().ne(0)]
MARKET = ['IHSG', 'SP500', 'VIX', 'OIL', 'GOLD', 'USDIDR']
rets = pd.DataFrame({c: eda[c].pct_change() * 100 for c in MARKET}, index=eda.index)
rets['IHSG_besok'] = rets['IHSG'].shift(-1)
rets = rets.dropna()

same_day = rets[MARKET].corr(method='spearman')
lead = rets[MARKET].corrwith(rets['IHSG_besok'], method='spearman').sort_values()

fig, axes = plt.subplots(1, 2, figsize=(14, 5), gridspec_kw={'width_ratios': [1.1, 1]})
sns.heatmap(same_day, annot=True, fmt='.2f', cmap='RdBu_r', center=0, vmin=-1, vmax=1, ax=axes[0],
            cbar_kws={'shrink': 0.8})
axes[0].set_title('Korelasi Spearman return hari yang sama')
colors = [C_UP if v > 0 else C_DOWN for v in lead.values]
axes[1].barh(lead.index + ' (hari t)', lead.values, color=colors)
axes[1].axvline(0, color=C_GREY, lw=1)
for i, v in enumerate(lead.values):
    axes[1].text(v + (0.005 if v >= 0 else -0.005), i, f'{v:+.3f}', va='center',
                 ha='left' if v >= 0 else 'right', fontsize=9)
axes[1].set_title('Korelasi return hari t dengan return IHSG hari t+1')
axes[1].set_xlim(lead.min() - 0.08, lead.max() + 0.08)
plt.tight_layout()
plt.savefig(FIG / '03_correlation_leadlag.png')
plt.show()
